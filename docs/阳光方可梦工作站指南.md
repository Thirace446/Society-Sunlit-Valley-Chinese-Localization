# Providence 的阳光方可梦工作站指南

本指南旨在为每种属性的宝可梦展示最佳工作选项及其获取途径。如果某类别的最佳宝可梦是传说、神话、悖谬或究极异兽，会给出替代方案。

## 基础规则

时间倍率 = 你的宝可梦对应能力值 ÷ 127.5。产出倍率（如适用）= 对应能力值 ÷ 127.5 × 100（百分比概率）。倍率超过 100% 时按预期生效：例如 150% 倍率意味着必定双倍产出，且有 50% 概率三倍产出。若宝可梦为异色，倍率与速度加成翻倍！
