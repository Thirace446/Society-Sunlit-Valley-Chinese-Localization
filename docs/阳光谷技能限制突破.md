# 技能限制突破教程

> **🔒 使用限制:修改结果禁止传播,仅限个人使用。** 传播方式包括且不限于文件分享、截图分享。非正常的传播会导致新玩家混淆整合包基础玩法,或引起正常流程玩家的反感。

> **⚠️ 警告:如果你的电脑上只有记事本可以编辑 JSON 文件,不建议尝试本教程。** JSON 文件对语法(引号、逗号、括号)非常敏感,记事本没有语法高亮和校验,稍有不慎就会改坏文件导致游戏报错。请先安装 VS Code 等专业编辑器,或在他人指导下操作。

基于 Puffish Skills 数据文件(如 `kubejs/data/society/puffish_skills/`)

---

## 1. 增加技能点上限

技能点上限由两个文件控制,需要同时修改:

### 1.1 修改 spent_points_limit

文件:`categories/<类别>/category.json`

```json
{
  "spent_points_limit": 12
}
```

将 `12` 改为想要的上限(如 `20`)。

各类别当前上限:

| 类别 | 当前上限 |
|---|---|
| farming(农业) | 12 |
| husbandry(畜牧) | 12 |
| mining(采矿) | 12 |
| fishing(钓鱼) | 12 |
| adventuring(冒险) | 12 |

### 1.2 补充经验值数组

文件:`categories/<类别>/experience.json`

```json
{
  "experience_per_level": {
    "type": "values",
    "data": {
      "values": [500, 1000, 2000, 4000, 8000, 10000, 12000, 16000, 20000, 22000, 24000, 30000]
    }
  }
}
```

数组元素数量 = 等级数。例如上限从 12 改为 15,则需在数组末尾追加 3 个经验阈值:

```json
"values": [500, 1000, 2000, 4000, 8000, 10000, 12000, 16000, 20000, 22000, 24000, 30000, 35000, 40000, 50000]
```

> 注意:数组元素少于上限时,新等级可能无法获得技能点。

## 2. 突破"只能选一条路线"的限制

### 2.1 限制的来源

文件:`categories/<类别>/connections.json`

每个技能树的连接文件分为两段:

```json
{
  "normal": {
    "bidirectional": [
      ["技能ID_A", "技能ID_B"]
    ]
  },
  "exclusive": {
    "bidirectional": [
      ["技能ID_C", "技能ID_D"]
    ]
  }
}
```

- **`normal`**:普通前置连接,解锁 A 后才能解锁 B(或互为前置)。
- **`exclusive`**:互斥连接,选了 C 就锁住 D(或反之)——这就是"只能选一条路线"的限制。

受影响的类别:farming、husbandry、mining、fishing、adventuring。

### 2.2 突破方法

二选一,推荐方案 A:

**方案 A:移到 normal 段**(两条路线都可走,但仍需各自前置)

```json
{
  "normal": {
    "bidirectional": [
      ["技能ID_C", "技能ID_D"]
    ]
  },
  "exclusive": {}
}
```

**方案 B:直接删除**(两条路线完全独立,无需前置)

```json
{
  "exclusive": {}
}
```

### 2.3 示例(farming 类别)

原文件 `categories/farming/connections.json` 中,tiller/artisan 等技能对存在于 `"exclusive"` 段:

```json
"exclusive": {
  "bidirectional": [
    ["cdo8sww4mya8uqzi", "z48upmi2is9hza58"],
    ["ml57kpgq73km1d62", "vsjhhjhckikbiy0p"],
    ["wuv57z31hlbytbgi", "nor5g3sfdkyl4pso"],
    ["37pcgymyw3ip6fpo", "rn2qqxmb5p3yqwfa"],
    ["4txqr6l6xvmthqvd", "f9r2hhqanzpnpdpc"]
  ]
}
```

修改后(将上述条目全部移入 `"normal"` 段,`"exclusive"` 清空):

```json
"normal": {
  "bidirectional": [
    ["cdo8sww4mya8uqzi", "z48upmi2is9hza58"],
    ["ml57kpgq73km1d62", "vsjhhjhckikbiy0p"],
    ["wuv57z31hlbytbgi", "nor5g3sfdkyl4pso"],
    ["37pcgymyw3ip6fpo", "rn2qqxmb5p3yqwfa"],
    ["4txqr6l6xvmthqvd", "f9r2hhqanzpnpdpc"]
  ]
},
"exclusive": {}
```

> 效果:tiller ↔ artisan 等互斥对不再互相锁定,两条路线可以同时点。

## 3. 通用步骤

1. 找到目标实例的 `kubejs/data/society/puffish_skills/` 目录。
2. 按需修改 `category.json`(点数上限)、`experience.json`(经验阈值)、`connections.json`(互斥限制)。
3. JSON 语法保持正确(注意逗号、引号)。
4. 重启游戏(数据包变更需重载世界或重启客户端)。

## 4. 注意事项

- 改动仅对**新存档**或**未满级**的角色完全生效;已有存档的技能进度不会自动回填新等级的技能点。
