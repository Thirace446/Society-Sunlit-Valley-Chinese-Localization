# 前瞻：阳光谷 2.0.0

正如我所说，我从没想过这个整合包会获得这么多关注！我一直在不断地往里加东西，而我的初始框架的种种缺陷，到了现在这个阶段已经相当明显了。2.0.0 版本本质上相当于一次重写——我会把许多系统重做，以提升质量与运行性能！

2.0.0 版本其实已经筹备了好一阵子了，但在我能有把握地公布之前，我一直不想声张！话虽如此，你们大概还是会有一些疑问：

## 问答环节

**问：我挺喜欢现在的阳光谷的！求别改。你到底要改什么！**

**答：**这不会变成一个面目全非的整合包！重做的重点会放在那些目前显得质量低下、或考虑不周的庞大系统上。我知道大家喜欢现在的样子（不然你也不会在这儿），所以玩法不会发生天翻地覆的变化。

**问：行吧行吧，那改动最大的是哪些？**

**答：**简单说几个：

- 作物会进行一次全面的重做与重新平衡，使其更贴近《星露谷物语》的机制——部分作物变为单次收获但价值更高，而另一些则像现在一样可多次收获。此外，烹饪也会逐道菜地彻底重做（最明显的一点，是“品质”以及许多随机工作站无法正确计算品质的问题）。
- 技能是我想重做的另一块内容。耕种与畜牧很可能会合并到同一棵技能树之下；而那些基本没人选、或平衡很差的技能，要么会被移除，要么会并入非技能类（或技能书，比如上古陈酿桶）。说不定还会新增一棵技能树（你大概能猜到是什么）！
- 钓鱼会有重大改动，并将切换到 Starcatcher 模组。我同时也在开发一款专门用于鱼塘的模组，这样我能做更多花样，也方便其他整合包使用！
- 整体性能与稳定性是另一个重点。一些添加了重复内容的模组会被移除，整合包的一些底层技术部分也会被重写，以大幅提升稳定性与性能。
- 最后，当然还会有一些我现在暂时保密的新内容。上面这份清单还非常不完整！

**问：那接下来几个版本，比如 4.1 呢？**

**答：**4.1 也在同步开发中，所以会比平时久一点。其余一切都要看 2.0.0 何时发布。

**问：阳光方可梦 也会跟着阳光谷一起更新吗？**

**答：**会，但不是同时进行。我想先让阳光谷稳定下来，再着手 阳光方可梦。

**问：什么时候发布 / 有预计时间吗 / 有相关消息吗？**

**答：**没有。如果你问，大家都会只回一句“3-4”然后不多解释。

**问：我还有别的问题。**

**答：**我大概也不会回答！直说吧，这是个大工程，如果我想在合理时间内做完，就得专心做包，而不是回答问题。请关注 dev-showcase 与 announcements 频道，我会持续更新进展，也谢谢大家的支持 ❤️

保持关注，keep it cottagecore！
