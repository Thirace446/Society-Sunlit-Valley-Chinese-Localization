# 生态祭坛 玩家指南

生态祭坛（Biodome Altar）是用来召唤封面传说宝可梦 **固拉多** 与 **盖欧卡** 的特殊建筑。

## 使用前准备

- 需要佩戴 **西尔佛检视镜** 才能与它互动。
- 主手持有对应的宝珠：
  - 召唤 **固拉多** → 朱红色宝珠
  - 召唤 **盖欧卡** → 靛蓝色宝珠
- 祭坛正上方要留空（空气或水），且周围 2 格内不能有其他宝可梦阻挡。

## 建造要求

扫描以祭坛为中心、**半径 16 格（含上下）** 的立方体区域，并统计以下方块的数量。把对应的东西在祭坛周围摆够，再右键祭坛即可。

> 表格中的「搜索标签」可以直接复制到 **JEI / EMI** 里搜索，查看该标签下所有符合条件的方块。

### 召唤固拉多（红宝石祭坛）

| 需要的东西 | 最少数量 | 搜索标签 | 常见可用方块举例 |
|------------|----------|--------------|------------------|
| 炽热建筑方块 | 125 | `#society:biodome_fire_building_blocks` | 各种石砖（石砖、深板岩砖、下界砖、黑石砖、磨制黑石等及其楼梯 / 台阶 / 墙），以及任意“墙”类方块 |
| 热源方块 或 岩浆 | 50 | `#society:biodome_fire_hot_blocks`（或 `minecraft:lava`） | 火盆、灵魂火盆、火把、营火、火、木炭块、火之石块 / 矿石、火焰石英，或直接围一圈岩浆 |
| 自然方块 | 75 | `#society:biodome_fire_natural_blocks` | 黑曜石、哭泣的黑曜石、岩浆块、下界岩、玄武岩、黑石、方解石、凝灰岩、深板岩、硫磺等 |

### 召唤盖欧卡（蓝宝石祭坛）

| 需要的东西 | 最少数量 | 搜索标签 | 常见可用方块举例 |
|------------|----------|--------------|------------------|
| 潮湿建筑方块 | 125 | `#society:biodome_water_building_blocks` | 海灯笼、海晶石 / 海晶石砖、水之石块 / 矿石、黏土、各类珊瑚块 |
| 水源方块 | 200 | `minecraft:water` | 任意水（用含水方块围出一片水域最方便） |
| 水生植物 | 50 | `#society:biodome_water_sea_plants` | 海草、睡莲等“水下骨粉”类植物 |
| 玻璃 | 50 | `#society:biodome_water_glass_blocks`（即 `#forge:glass`） | 任意玻璃（含染色玻璃） |
| 水生动物 | 5 | `society:biodome_water_animals`（即 `#forge:fishes` 与 unusualfishmod 的生物） | 在祭坛 10 格范围内放至少 5 条鱼 |

## 小贴士

- **不确定某个方块算不算数？** 把上表「JEI 搜索标签」里的标签名直接粘进 **EMI / JEI** 搜索，就能看到该类别下所有可用方块。
- 满足条件后右键祭坛即可触发，成功时会播放特效并召唤宝可梦。
- 召唤盖欧卡时天气会转雨，召唤固拉多时会放晴——属于正常现象。
