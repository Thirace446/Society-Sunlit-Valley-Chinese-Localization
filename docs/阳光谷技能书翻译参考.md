## 翻译策略总结

多数技能书使用以下手法构成：

1. **谐音/单词替换**：将名著标题中的关键词替换为游戏相关词汇
   - Blood Meridian → **Bluegill Meridian** → 蓝色子午线
   - Slaughterhouse-Five → **Pond House Five** → 池塘小屋五号
   - Crime and Punishment → **Brine and Punishment** → 渍与罚（渍~罪）

2. **直用原名但改品类**：整体结构不变，改末端名词
   - *Universal Methods of Design* → Universal Methods of **Farming** → 通用耕种方法
   - *Women Who Run with the Wolves* → Women Who Run with the **Plushies** → 与毛绒玩偶共奔的女人

3. **直用原名但首词替换**
   - *Anna Karenina* → **Banana** Karenina → 香蕉卡列尼娜
   - *The Sun Also Rises* → The **Spark** Also Rises → 火花照常升起
   - *Macbeth* → **Muk**beth → 姆克白

4. **杂志系列**（Minecraft 原版格式，非文学参考）
   - Mining **Monthly** → 采矿**月刊**
   - Combat **Quarterly** → 战斗**季刊**
   - Wet **Weekly** → 湿润**周刊**
   - Husbandry **Hourly** → 畜牧**时刊**
   - Yard Work **Yearly** → 院务**年刊**

5. **短词替换的结构对齐**（如保留"Z 与 Y"结构）
   - 罪与罚 → **渍与罚**（保留"X与Y"结构，只换首字）
   - 红与黑 → **红与黑**（完全保留原名）

6. **关联参考作品的译名**
   - "快击慢打"对应"快与慢"，关联《思考，快与慢》
   - "呼啸原木"对应"呼啸"，关联《呼啸山庄》
   - "向艺术跋涉"对齐原作译名，关联《向伯利恒跋涉》
   - "火花照常升起"对应"照常"，关联《太阳照常升起》
   - "加拿大名流"双关"加拿大·名流"，关联品牌 *Naked and Famous*
   - "公牛鱼工作"对齐"狗屁工作"的"XX工作"结构
